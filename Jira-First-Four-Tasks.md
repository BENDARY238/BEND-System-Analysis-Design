**Reference:** `Task-1/`

**Scope and deliverables:**
- Current Problem Statement: separate paper/Excel records across three branches and the online store; quantify the reported impact; distinguish symptoms from root cause; label figures as initial estimates requiring validation.
- Project Description: project goal, inputs/outputs, system boundary, users vs. stakeholders, eight high-level capabilities, assumptions and out-of-scope items.
