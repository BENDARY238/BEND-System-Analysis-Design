# BEND Integrated Shoe Store Management System

**Course:** System Analysis and Design
**Project:** An integrated management system for BEND, a multi-branch shoe retailer (3 branches + an online store).

This repository documents our work on the project step by step, one task at a time, as if we were running the project in a real company.

## How this repository is organized

Each task has its own folder (`Task-1`, `Task-2`, and so on). Inside each folder there is one document per part of the task. Every document lists the steps, who worked on each step, what each person did, the output, and a checklist.

## Task 1 documents

1. [Current Problem](Task-1/1_Current_Problem.docx): how BEND works today, the problem, its impact, and its root cause.
2. [Project Description](Task-1/2_Project_Description.docx): what we will build, the system boundary, users, and main capabilities.
3. [System Request](Task-1/3_System_Request.docx): the request submitted to the approval committee.
