**Course:** System Analysis and Design  
**Project:** Integrated management system for BEND, a multi-branch shoe retailer (3 branches + online store).

This repository contains the project tasks as separate folders. Each task document records the scope, steps, responsibilities, outputs and completion checklist.

## Repository structure

- `Task-1/` – Existing Current Problem, Project Description and System Request documents.
- `Task-2/` – Technical, economic and organizational feasibility.
- `Task-3/` – Three-year cash flow, ROI and break-even analysis.
- `Task-4/` – Methodology comparison and selection rationale.
- `Task-5/` – Project time estimate and planning task identification.
- `Task-6/` – Activity network, PERT interpretation, critical path and Gantt schedule.
- `Task-7/` – Three interview plans, question sets and report templates.
- `Task-8/` – Staff and customer questionnaires, screening questions and blank answer records.

## Important completion notes

1. Tasks 2–6 use the figures and planning assumptions in `BEND_Project_Report.docx`.
2. Task 7 report templates are intentionally blank. The source project report identifies its sample interview as illustrative and says real interview notes must replace it.
3. Task 8 contains draft questionnaires. No survey answers were provided, so no fictional responses or results have been entered. Collect real responses before marking the task Done.
4. The customer questionnaire in Task 8 is a proposed second questionnaire to satisfy the two-questionnaire requirement; review it with the project team before publishing.
5. Dates in the schedule are working days from project start, as in the source report.

## Recommended GitHub update workflow

1. Open the `BEND-System-Analysis-Design` repository.
2. Choose **Add file → Upload files**.
3. Upload the new `Task-2` through `Task-8` folders and replace `README.md` with this updated version.
4. Commit the changes with a clear message, for example: `Add Tasks 2-8 project documents and update README`.
5. Verify that each folder and document opens correctly before sharing the repository link.
